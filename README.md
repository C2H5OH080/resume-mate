# AI 简历助手 (ResumeMate)

> 一个浏览器插件：**填一次个人信息**，打开招聘网站后**一键抓取/截屏岗位**，AI 自动生成**匹配该岗位的定制简历**，支持**逐段润色 + 对话式修改**，最终**导出排好版的 PDF**。可自定义 API 接入任意模型（OpenAI 兼容协议）。

## ✨ 核心功能

1. **一次填写，永久复用** —— 个人信息（教育/工作/项目/技能/证书）存本地，换岗再投不用重复填。
2. **导入旧简历智能分析** —— 粘贴文本或上传 txt/md/图片，AI 自动提取结构化资料并给出改进建议。
3. **两种抓取方式** —— `📋 读取页面文字`（快、任意模型可用）或 `📸 截屏识别`（视觉模型，适合复杂排版）。
4. **AI 解析岗位** —— 自动提取公司/岗位/薪资/职责/要求/关键词，可手动修正。
5. **生成定制简历** —— 用 STAR 法则 + 量化成果，把关键词对齐到目标岗位。
6. **逐段润色 + 对话修改** —— 每一段单独「✨ 润色」，或到「对话」页用自然语言让 AI 直接改简历。
7. **导出排好版 PDF** —— 一键生成 A4 排版 PDF（中文排版、多页、分点），另支持复制 / 下载 Markdown。
8. **自定义模型** —— 填你自己的 API（Key / Base URL / 模型名），兼容所有 OpenAI 协议服务。

## 🚀 安装（本地试用）

1. 克隆/下载本仓库。
2. 打开 Chrome，地址栏输入 `chrome://extensions/`。
3. 右上角打开 **「开发者模式」**。
4. 点击 **「加载已解压的扩展程序」**，选择 `resume-ai-extension` 文件夹。
5. 点击插件图标 → 右上角 **⚙️ 设置**，填入个人信息 + API Key，保存。

> 首次使用会申请 `activeTab` / `scripting` / 存储权限，以及访问你配置的 API 地址所需的主机权限——均为正常功能所需。

## 🧭 使用步骤

1. （可选）「简历」页 → **📥 导入旧简历** → 粘贴或上传 → **✨ 智能分析并导入**，自动填好个人资料。
2. 打开一个招聘职位详情页 → 插件「岗位」页 → 点 **「📋 读取页面文字」**（或 **「📸 截屏识别」**）。
3. 核对 AI 解析出的岗位信息（可手动改）→ 点 **「✨ 生成定制简历」**。
4. 每段可点 **「✨ 润色」**；或到 **「对话」页** 输入指令（如"把项目经历写得更量化"）让 AI 直接改。
5. **「📄 导出 PDF」**（排好版，直接下载）/「📋 复制」/「⬇️ 下载 .md」。

## 🔌 自定义 API（预留的接口 / 盈利点）

插件不绑定任何厂商，所有 AI 请求走 **OpenAI 兼容协议**：

```
POST {baseUrl}/chat/completions
Authorization: Bearer {apiKey}
{ "model": "...", "messages": [...] }
```

- 默认 `baseUrl` = `https://api.openai.com/v1`
- 支持文本模型（`model`）与视觉模型（`visionModel`）分别配置
- 任何兼容该协议的服务（OpenAI、各类中转站、本地 `ollama` 等）改一下 `baseUrl` 即可接入

**这就是你的盈利点**：将来做一个「中转站」，用户只需把你的中转站地址填进 `baseUrl`、配上 Key，即可通过你统一计费/分发流量。插件端**无需任何改动**，因为接口协议已经留好。

## 🔒 隐私

- 所有数据（个人信息、API Key）仅保存在**浏览器本地** `chrome.storage.local`，不经过任何第三方服务器。
- 截图/文字只发给你自己配置的 API 地址。
- 不上传、不统计、无遥测。

- 截图仅捕获**当前可见区域**，超长页面请滚动后分段截取，或优先用「读取页面文字」。
- 生成/润色过程请保持弹窗打开（关闭弹窗会中断请求）。
- `host_permissions` 目前为 `<all_urls>`，是为支持任意自定义 API 地址；生产发布时可按需收敛为具体域名。
